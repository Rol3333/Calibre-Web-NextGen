### Added

- **Open Library lookups by ISBN now return the exact edition, with its series.** A query of the form `isbn:<isbn>` (and the auto-fetch's ISBN retry) goes straight to Open Library's edition endpoint instead of the title search, so the record carries the edition's own publisher, year, subjects, cover, LCCN and Internet Archive id, and the series statement is read from the edition's MARC 830/490 fields. Foreground MARC lookups are bounded so a slow Archive.org cannot stall the search dialog.
- **The Open Library search data is saved beside the book.** After a successful metadata apply — the ingest auto-fetch, the manual metadata form, the SPA edit save, or the bulk title/author swap — a background task writes `data/openlibrary/edition.json`, one `marc_<n>_<item>_<offset>.mrc` per source record, and a `sources.json` manifest with each file's locator, SHA-256 and fetch time. A metadata search from a book's edit page also queues the save, so the data is written as soon as the search succeeds. The manifest is the completion record: a run that saved the edition but could not fetch every MARC source is marked `partial` and retried later (only the missing records, verified against their SHA-256), while `complete`/`no_marc` runs for the same ISBN are skipped. A failed edition request still writes a failure manifest. Files are written atomically and the manifest last, so an interrupted run never looks complete. Open Library and Archive.org calls are throttled and backed off, and the task honours cancellation. This is separate from the library metadata backup (`metadata.opf`).
- **Open Library search requests now go through the shared HTTP service.** The regular `/search.json` request uses the same rate limiter as the edition and MARC calls, with explicit timeouts, bounded retries with exponential backoff + jitter for connection errors, timeouts, 429 and transient 5xx, and `Retry-After` support. Permanent 4xx errors are not retried, and a failed search is logged with its failure information rather than being indistinguishable from an empty result.
- **Cover staging no longer crashes on Windows.** The POSIX-only `os.fchmod` call in the cover storage path is now guarded, so saving a cover works on platforms without it.
