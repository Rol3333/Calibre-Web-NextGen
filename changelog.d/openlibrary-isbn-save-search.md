### Added

- **Open Library lookups by ISBN now return the exact edition, with its series.** A query of the form `isbn:<isbn>` (and the auto-fetch's ISBN retry) goes straight to Open Library's edition endpoint instead of the title search, so the record carries the edition's own publisher, year, subjects, cover, LCCN and Internet Archive id, and the series statement is read from the edition's MARC 830/490 fields. Foreground MARC lookups are bounded so a slow Archive.org cannot stall the search dialog.
- **The Open Library search data is saved beside the book.** After a successful metadata apply — the ingest auto-fetch or a manual apply from the metadata modal — a background task writes `data/openlibrary/edition.json`, one `marc_<n>_<item>_<offset>.mrc` per source record, and a `sources.json` manifest with each file's locator, SHA-256 and fetch time. The manifest is the completion record: a run that saved the edition but could not fetch every MARC source is marked `partial` and retried later, while `complete`/`no_marc` runs are skipped. Files are written atomically and the manifest last, so an interrupted run never looks complete. Open Library and Archive.org calls are throttled and backed off, and the task honours cancellation. This is separate from the library metadata backup (`metadata.opf`).
